# Session-02
Session 2 files  Creativa Front-End course


 About the Project

This is a simple HTML project created to practice the basics of web development.

## Features

* Displaying images using the `<img>` tag.
* Creating links to other pages using the `<a>` tag.
* Adding social media links.
* Creating email and phone links.
* Building tables using HTML.
* Merging table cells using `rowspan`.

##  Technologies Used

* HTML5

##  What I Learned

* How to add images to a webpage.
* How to create internal and external links.
* How to add contact information.   
* How to create and organize HTML tables.
* How to merge table cells.
